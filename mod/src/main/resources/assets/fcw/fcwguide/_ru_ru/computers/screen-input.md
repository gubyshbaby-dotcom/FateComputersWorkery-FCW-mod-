# Мониторы и ввод

Монитор показывает экран привязанного компьютера прямо в мире. Чтобы работать за компьютером, нужно сесть за него.

| Действие | Как |
|---|---|
| Сесть за компьютер | ПКМ по монитору или клавиатуре |
| Выйти | правый Ctrl (меняется в настройках управления) |
| Перехватить управление у другого игрока | щелчок по экрану |

Пока игрок сидит за компьютером, экран занимает всё окно игры, а клавиатура и мышь идут в гостевую систему.

## Что для чего нужно

| Устройство | Без него |
|---|---|
| Монитор (ЖК или ЭЛТ) | экран не виден |
| Клавиатура | нет ввода с клавиатуры |
| Мышь | нет ввода мышью |
| Колонки | у машины нет звуковой карты |

ЖК и ЭЛТ мониторы показывают одно и то же, различается только модель. Колонки пяти видов тоже равноценны.

## Ограничения

- Компьютером управляет один игрок. Остальные видят экран на мониторе.
- Живой экран виден на мониторе с 32 блоков; дальше монитор показывает статичную картинку.
- Разрешение графического экрана задаёт сервер: 1024 x 768 по умолчанию.
- С настройкой `access.ownerOnlyControl` управлять может только тот, кто поставил компьютер.
