# Сервер и администратор

Виртуальные машины работают там, где запущен сервер Minecraft: в одиночной игре на компьютере игрока, в сетевой на сервере.

## Что нужно серверу

| | |
|---|---|
| QEMU | `qemu-system-x86_64` и `qemu-img`; если их нет, мод сам скачивает переносимую сборку |
| Ускорение | KVM на Linux, WHPX на Windows, HVF на macOS; без него машины работают в медленной программной эмуляции |
| Порт | UDP 25600 открыт для игроков: по нему идут экран, ввод и звук |
| Память | на каждый включённый компьютер: от 256 МБ для консоли, 1–2 ГБ для рабочего стола |
| Диск | 1–1,5 ГБ на образ ОС и место под диски машин |

## Первые шаги

1. Проверить состояние: `/fcw status`.
2. Скачать образ: `/fcw images fetch fedora`.
3. Если сервер за NAT, указать внешний адрес в `daemon.publicHost`.

## Хостинг в контейнере

На Pelican и Pterodactyl нет доступа к KVM внутри контейнера. Варианты: работать в программной эмуляции или поставить демон виртуальных машин службой на сам узел (`daemon.mode = "remote"`).
