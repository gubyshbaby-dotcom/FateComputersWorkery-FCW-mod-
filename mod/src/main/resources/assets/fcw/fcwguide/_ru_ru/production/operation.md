# Управление машинами

Страница описывает нынешнюю версию. Способ загрузки и запуска машин перерабатывается и изменится.

## Установка и разбор

- Дуговая печь, ростовая печь, участок резки и линия электроники ставятся комплектом: ПКМ по земле. Машина встаёт целиком, пультом к игроку. Если места не хватает, мешающие блоки отмечаются красной пылью.
- Литограф EUV строится из блоков набора: [Постройка литографа](euv-building.md).
- Разбор: сломать любую клетку машины с зажатым Shift. Выпадают комплект и содержимое слотов. Литограф снова становится блоками набора.

## Работа

1. Включить главный рубильник (ПКМ).
2. Положить предметы во входные слоты: через окно пульта (ПКМ по пульту) или через порт загрузки.
3. Рецепт запускается сам, когда входов хватает, а в выходных слотах есть место.
4. Забрать результат из окна пульта или с порта выдачи.

Если подходят несколько рецептов, машина берёт тот, где больше разных входов, затем тот, где больше предметов. Кладите ровно то, что нужно для нужного результата.

## Состояния

| Состояние | Причина |
|---|---|
| Выключена | рубильник выключен |
| Ожидание | нет подходящего рецепта во входных слотах |
| Работает | идёт рецепт |
| Нет энергии | включён режим `requirePower`, а в буфере не хватает FE |
| Выход заполнен | результат не помещается в выходные слоты |

## Порты

- Порты предметов работают как инвентари: к ним подключаются воронки и трубы других модов. Порт загрузки кладёт во входные слоты, порт выдачи отдаёт из выходных.
- Порт питания принимает FE: [Энергия](../energy/index.md).
- Порты жидкостей принимают жидкости, но рецептам этой версии они не нужны.
- Двери и лотки открываются ПКМ; во время работы машина открывает и закрывает их сама.

Скорость всех рецептов меняет настройка `production.speedMultiplier`.
