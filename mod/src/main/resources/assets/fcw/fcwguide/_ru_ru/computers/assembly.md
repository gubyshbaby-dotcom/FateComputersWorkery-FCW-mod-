# Сборка и запуск

1. Поставить корпус. Системный блок и шесть корпусов работают одинаково, отличается только вид.
2. Поставить рядом монитор, клавиатуру, мышь, колонки. Устройство само привязывается к ближайшему компьютеру в радиусе 8 блоков.
3. ПКМ по корпусу: окно компьютера. Вставить материнскую плату, процессор, память (до 4 модулей), при необходимости видеокарту.
4. Выбрать операционную систему и нажать «Включить».
5. ПКМ по монитору или клавиатуре: сесть за компьютер. Выход: правый Ctrl.

## Привязка устройств

Привязать устройство к другому компьютеру: Shift+ПКМ пустой рукой по компьютеру, затем Shift+ПКМ по устройству. Значки под кнопкой «Включить» показывают, что привязано: монитор, клавиатура, мышь, колонки.

## Кнопки окна

| Кнопка | Действие |
|---|---|
| Включить, Выключить | запуск и штатное завершение работы |
| Обесточить | немедленная остановка машины |
| Переустановить | стирает диск и ставит выбранную ОС заново |
| Обновить ОС | появляется, когда вышла новая сборка образа; тоже стирает диск |

## Что важно

- Детали меняются только на выключенном компьютере.
- Если сломать блок компьютера, диск его машины удаляется.
- Имя, данное компьютеру на наковальне, становится его именем в сети.
