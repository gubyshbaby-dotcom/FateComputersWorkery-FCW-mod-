# Настройки

Два файла в папке `config`: `fcw-server.toml` (сервер; в одиночной игре тоже действует) и `fcw-client.toml` (клиент). Ниже основные ключи; у каждого ключа в файле есть комментарий.

## fcw-server.toml

### daemon: демон виртуальных машин

| Ключ | По умолчанию | Значение |
|---|---|---|
| `enabled` | true | использовать демон |
| `mode` | local | local: сервер запускает демон сам; remote: подключается к службе на узле |
| `remoteAddress`, `remoteToken` | | адрес и секрет для режима remote |
| `qemuPath` | пусто | путь к `qemu-system-x86_64`; пусто: искать автоматически |
| `qemuAutoDownload` | true | скачать переносимый QEMU, если своего нет |
| `quicPort` | 25600 | порт UDP для экранов, ввода и звука |
| `publicHost`, `publicPort` | пусто, 0 | внешний адрес и порт, если сервер за NAT |
| `maxVms` | 4 | сколько машин работает одновременно |
| `accelerator` | auto | auto, kvm, whpx, hvf или tcg |

### vm: виртуальные машины

| Ключ | По умолчанию | Значение |
|---|---|---|
| `lang` | ru_RU.UTF-8 | язык гостевой системы |
| `keyboardLayouts` | us,ru | раскладки |
| `network` | true | сетевая карта и сеть `.mc` |
| `maxMemoryMb` | 8192 | предел памяти одной машины |
| `displayWidth`, `displayHeight` | 1024, 768 | разрешение графического экрана |
| `restartRunningOnLoad` | true | включать после перезапуска сервера машины, которые работали |

### network: сеть гостей

| Ключ | По умолчанию | Значение |
|---|---|---|
| `internet` | true | выход в интернет через NAT |
| `rateLimitKiBps` | 8192 | лимит скорости на машину, КиБ/с |
| `allow` | пусто | адреса CIDR, разрешённые вопреки файрволу |
| `deny` | пусто | дополнительные запрещённые адреса CIDR |

### access: устройства и доступ

| Ключ | По умолчанию | Значение |
|---|---|---|
| `linkRadius` | 8 | радиус привязки устройств, блоков |
| `viewDistance` | 128 | дальше этого расстояния экран игроку не выдаётся |
| `ownerOnlyControl` | false | управлять может только владелец компьютера и операторы |

### production: машины

| Ключ | По умолчанию | Значение |
|---|---|---|
| `requirePower` | false | true: машины работают только от FE |
| `speedMultiplier` | 1.0 | скорость всех рецептов: 2.0 вдвое быстрее |

### cinema: кино

| Ключ | По умолчанию | Значение |
|---|---|---|
| `projectorRange` | 24 | на сколько блоков светит проектор |
| `lampLifeHours` | 40 | ресурс лампы проектора в часах проекции; 0: лампы не изнашиваются |
| `projectorPower` | 30 | расход проектора, FE за тик, при `requirePower = true` |

## fcw-client.toml

| Ключ | По умолчанию | Значение |
|---|---|---|
| `screens.renderDistance` | 32 | дальше этого расстояния монитор показывает статичную картинку |
| `screens.nearFps`, `screens.farFps` | 30, 5 | частота кадров близких и дальних экранов |
| `screens.farDistance` | 12 | с какого расстояния экран считается дальним |
| `screens.controlFps` | 60 | частота кадров, пока игрок сидит за компьютером |
| `audio.enabled`, `audio.volume` | true, 1.0 | звук компьютеров через колонки |
| `cinema.projectorBeam` | true | рисовать луч проектора и пыль в нём |
