# Детали без машин

Младшие детали делаются на верстаке. Их хватает на первый компьютер с текстовой консолью и на детали самих машин.

| Деталь | Что даёт |
|---|---|
| Процессор 8-бит (DIP) | 1 vCPU |
| Процессор 16-бит (QFP) | 1 vCPU; нужен для фотошаблонов и комплектов |
| Микросхема памяти (DIP) | 256 МБ |
| Модуль памяти SIMM | 512 МБ |
| Заготовка платы | основа плат и модулей памяти |
| Материнская плата | на верстаке дороже, чем на линии электроники |
