# Команды /fcw

| Команда | Кому | Действие |
|---|---|---|
| `/fcw status` | всем | состояние демона виртуальных машин, ускоритель, сеть, адрес для клиентов |
| `/fcw images` | всем | список образов ОС и какие из них скачаны |
| `/fcw images fetch id` | оператор | скачать и установить образ: `fedora`, `ubuntu`, `arch` |
| `/fcw vms` | оператор | машины, известные демону, и их состояние |
| `/fcw qemu` | всем | какой QEMU найден |
| `/fcw qemu fetch` | оператор | скачать переносимый QEMU |
| `/fcw recipes` | оператор | число загруженных рецептов машин и самопроверка поиска рецептов |
| `/fcw machine place имя` | оператор | поставить готовую машину перед собой, без стройки |
| `/fcw machine blank` | оператор | выложить заготовку литографа из блоков набора |

Оператор: уровень прав 2.

Имена машин для `/fcw machine place`: `arc_furnace`, `crystal_puller`, `wafering_cell`, `euv_scanner_mk2`, `chip_line`.

## В гостевой системе

| Команда | Действие |
|---|---|
| `fcw redstone get` | входной сигнал на всех сторонах |
| `fcw redstone get front` | входной сигнал на одной стороне |
| `fcw redstone set top 15` | выдать сигнал на сторону |
| `fcw info` | состояние связи с игрой |
| `fcw machine list` | машины в сети этого компьютера: имя, тип, состояние |
| `fcw machine euv-1 status` | любая команда пульта для машины с этим именем |
| `fcw machine euv-1 log 20 --follow` | журнал; новые записи печатаются по мере появления |
| `fcw machine euv-1 wait idle --timeout 600` | ждать состояния `idle`, `run` или `fault` |
| `fcw top` | полноэкранная сводка по машинам сети |
| `fcw litho euv-1`, `fcw mon euv-1` | полноэкранная программа машины: карта пластины, брак, журнал |
| `fcw yield` | отчёт за смену |
| `fcw apc on`, `fcw apc off`, `fcw apc status` | служба расчёта поправок для машин |

Подробнее: [Редстоун и fcw](../computers/redstone.md), [Программы компьютера](../production/programs.md).

## Машины с компьютера

Компьютер видит машины, с которыми соединён кабелем данных, и машины в радиусе маршрутизатора в той же сети. Команды те же, что на пульте: `status`, `start`, `stop`, `recipe`, `log`, `name`, `yield`, а на стройплощадке ещё `bom`, `stage`, `cancel`. Описание команд: [Управление машинами](../production/operation.md).

- Ключ `--json` печатает ответ в JSON: для скриптов.
- Код выхода 0 означает успех, 1 отказ, 2 означает, что машины нет в сети или игра не отвечает.
- Язык ответа берётся из локали гостевой системы.

## Пульт машины и поддон

ПКМ пустой рукой по пульту машины или по поддону стройплощадки открывает ту же консоль в игре, без компьютера. `help` печатает список команд, `exit` закрывает консоль.
