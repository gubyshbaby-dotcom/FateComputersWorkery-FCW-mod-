# Энергия

Машины считают энергию в FE (Forge Energy). Расход указан в каждом рецепте: FE за тик и всего за цикл.

## Режимы

| `production.requirePower` | Поведение |
|---|---|
| `false` (по умолчанию) | машины работают от встроенного трансформатора и FE не требуют |
| `true` | рецепт идёт, только пока в буфере машины хватает FE |

Режим один на весь сервер и задаётся в `fcw-server.toml`.

## Подключение

| | |
|---|---|
| Порт | ввод питания, сзади машины; красная рамка на сценах |
| Буфер | 400 000 FE |
| Приём | до 20 000 FE/т |
| Источник | генераторы и кабели любого мода с FE |

Если энергия кончилась посреди рецепта, машина останавливается с состоянием «Нет энергии» и продолжает с того же места, когда в буфере наберётся запас на одну секунду работы.

## Сколько нужно

| Машина | FE/т |
|---|---|
| Дуговая печь | 256–384 |
| Ростовая печь | 512 |
| Резка и полировка | 256 |
| Литограф EUV | 1024–2048 |
| Линия электроники | 256–768 на участок |
| [Проектор](../computers/cinema.md) | 30, пока горит лампа |

Самый дорогой цикл: пластина с процессорами, 2 457 600 FE за 60 секунд.

Своих генераторов в моде пока нет: они проектируются. До их появления используйте режим по умолчанию или источники FE из других модов.
