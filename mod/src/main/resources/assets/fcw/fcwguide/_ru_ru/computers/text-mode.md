# Текстовый режим

Компьютер без видеокарты показывает на мониторе текстовую консоль 80 x 25 символов вместо рабочего стола.

| | |
|---|---|
| Что нужно | материнская плата, процессор, память от 256 МБ |
| Вход | автоматический, пользователь `user` |
| Терминал | `xterm-256color`, цвет и псевдографика работают |
| Устройства | монитор и клавиатура; мышь не используется |

Текстовый режим запускается быстрее графического и тратит меньше памяти сервера. Его достаточно для сети, скриптов и управления редстоуном.

Первый компьютер из деталей с верстака работает именно так: процессор DIP и микросхема памяти DIP дают 1 ядро и 256 МБ.

Чтобы получить рабочий стол, выключите компьютер, вставьте видеокарту и доведите память до 1 ГБ или больше.
