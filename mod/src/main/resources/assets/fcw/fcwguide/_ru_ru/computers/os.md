# Операционные системы

| id образа | Система |
|---|---|
| `fedora` | Fedora 45 |
| `ubuntu` | Ubuntu 26.04 LTS |
| `arch` | Arch Linux |

Во всех трёх одинаковое окружение: рабочий стол labwc с панелью LXQt, терминал Alacritty.

| | |
|---|---|
| Пользователь | `user` |
| Пароль | `fcw` |
| Права администратора | `sudo` |
| Терминал | Super+Enter или Ctrl+Alt+T |
| Раскладки | us и ru, переключение Alt+Shift |

## Установка образа

Образы скачивает администратор сервера: `/fcw images fetch fedora` (также `ubuntu`, `arch`). Список и состояние: `/fcw images`. Один образ занимает 1–1,5 ГБ на диске сервера.

## Диск машины

У каждого компьютера свой диск: тонкий слой поверх общего образа. Всё, что установлено и сохранено в системе, остаётся на этом диске между включениями.

Диск стирается в трёх случаях: кнопка «Переустановить», кнопка «Обновить ОС», разрушение блока компьютера.

## Обновление

Версия образа закреплена за машиной. Когда администратор ставит новую сборку образа, старые машины продолжают работать на своей версии, а в окне появляется «Обновить ОС».
