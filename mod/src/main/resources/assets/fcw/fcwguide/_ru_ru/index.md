# Справочник Fate Computers Workery

Мод добавляет компьютеры, в каждом из которых работает виртуальная машина с Linux, и производственную цепочку, на которой делают детали для них.

- [Компьютеры](computers/index.md): сборка, детали, ОС, экран и ввод, сеть, редстоун.
- [Производство](production/index.md): пять машин от кварца до процессоров, рецепты, фотошаблоны, теги чипов.
- [Энергия](energy/index.md): FE и настройка `requirePower`.
- [Команды и настройки](reference/index.md): `/fcw` и файлы конфигурации.

## Как читать

Трёхмерные сцены вращаются мышью, колесо меняет масштаб. Рамки на сценах машин отмечают порты; название порта видно при наведении.

| Рамка | Порт |
|---|---|
| голубая | вход предметов |
| жёлтая | выход предметов |
| красная | питание, FE |
| синяя | жидкость |
| белая | управление |

Если установлен мод Ponder, у комплектов машин и у блоков литографа есть анимированные сцены: удерживайте клавишу Ponder (по умолчанию W) над предметом в инвентаре.
