# Сеть .mc

Все включённые компьютеры одного сервера находятся в общей локальной сети. Настраивать ничего не нужно: адрес выдаётся по DHCP.

| | |
|---|---|
| Шлюз, DHCP и DNS | 10.42.0.1 |
| Имя компьютера | `имя.mc` |
| Имя по умолчанию | `pc-` и восемь знаков, например `pc-1a2b3c4d` |

## Имя компьютера

Переименуйте корпус на наковальне до установки. Имя приводится к строчным латинским буквам, цифрам и дефису; кириллица транслитерируется. Компьютер «Сервер 1» станет `server-1.mc`.

Имя и адрес видны в окне компьютера в строке «Сеть».

## Проверка

Из одного компьютера до другого:

```
ping server-1.mc
```

Между компьютерами работают любые протоколы: SSH, HTTP, свои серверы на любых портах.
