# Комплектующие

Детали вставляются в окно компьютера. От них зависит, сколько ядер и памяти получит виртуальная машина.

| Слот | Обязателен | Что даёт |
|---|---|---|
| Материнская плата | да | без неё компьютер не включится |
| Процессор | да | число ядер (vCPU) |
| Память, 4 слота | хотя бы один модуль | объём памяти, модули складываются |
| Видеокарта | нет | графический экран и рабочий стол |

## Процессоры

| Процессор | vCPU | Где делают |
|---|---|---|
| 8-бит (DIP) | 1 | верстак |
| 16-бит (QFP) | 1 | верстак |
| 32-бит (PGA) | 2 | линия электроники |
| 64-бит | 2 | линия электроники |
| Многоядерный | 4 | линия электроники |
| Серверный | 8 | линия электроники |

Машина не получит больше ядер, чем есть у сервера.

## Память

| Модуль | МБ | Где делают |
|---|---|---|
| Микросхема DIP | 256 | верстак |
| SIMM | 512 | верстак |
| DIMM | 1024 | линия электроники |
| DDR | 2048 | линия электроники |
| SO-DIMM | 2048 | линия электроники |
| DDR с подсветкой | 4096 | линия электроники |
| Серверная | 8192 | линия электроники |

Предел на одну машину задаёт настройка `vm.maxMemoryMb` (по умолчанию 8192 МБ). Текстовой консоли хватает 256 МБ. Рабочему столу нужно не меньше 1 ГБ, лучше 2 ГБ; точный минимум для каждой ОС показан в списке образов.

Рецепты деталей: [Детали без машин](../production/workbench.md), [Линия электроники](../production/chip-line.md).
