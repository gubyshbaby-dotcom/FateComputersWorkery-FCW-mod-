# Parts without machines

The low-end parts are made at a workbench. They are enough for a first computer with a text console and for the parts of the machines themselves.

| Part | Gives |
|---|---|
| 8-bit CPU (DIP) | 1 vCPU |
| 16-bit CPU (QFP) | 1 vCPU; needed for reticles and kits |
| Memory chip (DIP) | 256 MB |
| SIMM memory module | 512 MB |
| Board blank | base of boards and memory modules |
| Motherboard | costs more at the workbench than on the electronics line |
