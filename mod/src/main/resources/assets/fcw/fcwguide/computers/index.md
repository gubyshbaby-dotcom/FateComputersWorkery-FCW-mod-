# Computers

A computer is a block with a QEMU virtual machine running Linux inside. The machine's screen is shown on a monitor in the world; input comes from the player's keyboard and mouse.

Needed for the first start:

1. A case, a monitor, a keyboard. Mouse and speakers are optional.
2. A motherboard, a processor, at least one memory module.
3. An OS image on the server. An administrator downloads it: `/fcw images fetch fedora`.

The cheapest set (case, CRT monitor, keyboard, DIP processor, DIP memory) is crafted at a workbench and gives a text console. A desktop needs a graphics card and 1 GB of memory or more.
