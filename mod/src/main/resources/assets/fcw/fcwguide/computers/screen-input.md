# Monitors and input

A monitor shows the screen of the linked computer right in the world. To work at the computer, sit at it.

| Action | How |
|---|---|
| Sit at the computer | right-click the monitor or the keyboard |
| Leave | right Ctrl (can be rebound in the controls) |
| Take control from another player | click on the screen |

While a player sits at the computer, the screen fills the game window and keyboard and mouse go to the guest system.

## What each device is for

| Device | Without it |
|---|---|
| Monitor (LCD or CRT) | the screen is not visible |
| Keyboard | no keyboard input |
| Mouse | no mouse input |
| Speakers | the machine has no sound card |

LCD and CRT monitors show the same picture; only the model differs. The five kinds of speakers are equal too.

## Limits

- One player controls a computer. Others see the screen on the monitor.
- The live screen is visible on a monitor from 32 blocks; farther away the monitor shows a still picture.
- The resolution of the graphical screen is set by the server: 1024 x 768 by default.
- With the `access.ownerOnlyControl` setting only the player who placed the computer can control it.
