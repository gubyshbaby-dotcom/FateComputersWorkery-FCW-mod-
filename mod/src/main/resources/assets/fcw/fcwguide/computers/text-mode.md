# Text mode

A computer without a graphics card shows a text console of 80 x 25 characters on its monitor instead of a desktop.

| | |
|---|---|
| Needed | motherboard, processor, 256 MB of memory or more |
| Login | automatic, user `user` |
| Terminal | `xterm-256color`; colour and box drawing work |
| Devices | monitor and keyboard; the mouse is not used |

Text mode starts faster than the desktop and takes less of the server's memory. It is enough for networking, scripts and redstone control.

The first computer made from workbench parts works this way: a DIP processor and a DIP memory chip give 1 core and 256 MB.

To get a desktop, shut the computer down, insert a graphics card and bring the memory to 1 GB or more.
