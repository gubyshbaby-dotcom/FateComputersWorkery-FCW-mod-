# Assembly and first start

1. Place a case. The system unit and the six cases work the same; only the look differs.
2. Place a monitor, keyboard, mouse and speakers nearby. A device links itself to the nearest computer within 8 blocks.
3. Right-click the case: the computer window. Insert a motherboard, a processor, memory (up to 4 modules) and, if needed, a graphics card.
4. Pick an operating system and press "Power on".
5. Right-click the monitor or the keyboard to sit at the computer. Leave with the right Ctrl key.

## Linking devices

To link a device to another computer: Shift + right-click the computer with an empty hand, then Shift + right-click the device. The icons under the power button show what is linked: monitor, keyboard, mouse, speakers.

## Window buttons

| Button | Action |
|---|---|
| Power on, Shut down | start and clean shutdown |
| Force off | stops the machine at once |
| Reinstall | wipes the disk and installs the chosen OS again |
| Update OS | appears when a new image build is out; also wipes the disk |

## Keep in mind

- Parts can be changed only while the computer is off.
- Breaking the computer block deletes the disk of its machine.
- A name given to the computer on an anvil becomes its network name.
