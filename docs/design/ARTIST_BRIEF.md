# ТЗ художнику: энергоблоки, автоматика, доработки машин

Minecraft Java 1.21.1, NeoForge. Пространство имён `pcmod`, как в прошлых наборах. Архивы:
`11_energy_blocks`, `12_automation`, `13_machine_updates` и, по желанию, `14_factory_decor`.
Можно сдавать по одному.

Подробности и числа: [ENERGY_BLOCKS.md](ENERGY_BLOCKS.md), [AUTOMATION.md](AUTOMATION.md),
[MACHINE_UI.md](MACHINE_UI.md). Схемы пропорций (не модели, только размеры и расположение
индикаторов): [mockups/concept_energy.png](mockups/concept_energy.png),
[mockups/concept_automation.png](mockups/concept_automation.png).

## Общие правила

- Стиль Mk2, как у литографа и печи v4: белые корпуса с панелями по блоку, вставки из чёрного
  стекла, чёрные анодированные рамы, по низу юбка цоколя, 2 текселя на 1/16 блока, лёгкий шум на
  белом. Медь только на шинах, клеммах и наконечниках.
- Сдержанно. Светятся только: световые линии состояния (тёмные — off, белые — idle,
  фиолетовые — run), сигнальные лампы, строки на маленьких экранах, огонь. Никакого декоративного
  свечения, голограмм, RGB.
- Перед модели — север, `facing=north` без поворота. Повороты элементов только 22,5° и 45°.
  У граней на границе блока `cullface`. Светящиеся грани — `neoforge_data` (15/15).
- Состояния off / idle / run — отдельными моделями или текстурами, как раньше. Анимированные
  текстуры: кадры стопкой + `.mcmeta`.
- Мультиблоки и всё с подвижными частями: манифест + файл анимаций формата `format: 1`
  (части, клипы, props, events, fx, emitters), блоки `<имя>_part` и `<имя>_hatch`, модели `dyn/`,
  `alt_blockstates` с «голыми» клетками, тот же Java-проигрыватель.
- У каждого блока модель предмета; у мультиблоков — иконка комплекта 32×32.
- В README: части, свойства и их значения, порты (клетка, грань, координаты в 1/16), люки,
  подвижные части (якорь, ось, ход), клипы, эмиттеры частиц, что проверено, чего нет.
- Превью-листы как раньше: общий вид, состояния, соединения, точки подключения с номерами.

### Кабель данных и роутер

Нужны для сети данных (компьютер видит машину по кабелю данных; роутер добавляет машины в своём
радиусе без кабеля).

- `data_cable`: должен с первого взгляда отличаться от силовых кабелей. Силовые — толстые, чёрные,
  с цветными кольцами. Кабель данных — тонкий (2/16), светло-серая оболочка, без колец; идёт парой
  жил вплотную (плоский в сечении, 3×2 /16). Multipart с теми же именами частей: `core` (маленькая
  серая коробка-разветвитель 4×4×4 /16, только на поворотах, отводах и концах), `arm_<6 сторон>`,
  `plug_<6 сторон>` (серый разъём с защёлкой у устройства и один зелёный светодиод: свойство
  `link` — погашен / горит), `clip_<6 сторон>` (скоба к стене). В одной клетке один кабель:
  рядом с силовым он кладётся в соседнюю клетку.
- `data_router`: корпус Mk2 12×4×10 /16 (плоская коробка) на кронштейне, одна антенна-штырь
  высотой 10/16 на шарнире (чёрная), спереди ряд из четырёх портов и индикатор связи из трёх
  делений. Свойства: `facing`, `mount` = floor / wall / ceiling (антенна всегда смотрит вверх,
  на потолке — вниз), `state` = off / idle (питание есть, машин в радиусе нет: одно деление
  белое) / run (связь есть: деления по числу машин, фиолетовые). Порты данных — все боковые грани.
  Бытовой роутер из первого набора остаётся как есть (сеть компьютеров); этот — заводской.

## Архив 12: автоматика

### Монорельс (подвесной)

Балка занимает верхние 6/16 клетки, тележка — нижние 10/16, капсула с грузом висит в клетке ниже.
Балка белая, подвесы чёрные, по низу балки световая линия состояния.

| № | блок | клетки | подвижные части | клипы |
|---|---|---|---|---|
| 1 | `monorail_track` | 1×1×1 | — | свойства `axis`, `hanger` = none / ceiling / post, `state` |
| 2 | `monorail_curve` | 2×1×2 | — | четыре ориентации |
| 3 | `monorail_turntable` | 1×1×1 | `table` (отрезок балки на круге, вокруг y, шаг 90°), огонь пути | `turn_cw`, `turn_ccw` по 0,8 с |
| 4 | `monorail_lift` | 1×N×1 | `cage` (люлька с отрезком балки, ход по y) | `lift_up`, `lift_down`, 1 с на клетку |
| 5 | `monorail_station` | 1×1×1 | `clamp_l`, `clamp_r` (ход x ±2) | `clamp_close`, `clamp_open` по 0,4 с |
| 6 | `monorail_depot` | 1×2×2 | `shutter` (ход по y) | `shutter_open`, `shutter_close` по 1 с |
| 7 | `monorail_post` | 1×N×1 | — | стойка-портал для улицы |
| 8 | `monorail_gate` | 1×1×1 | `door_l`, `door_r` (ход вбок) | `gate_open`, `gate_close` по 0,5 с |

На корпусе станции: трёхпозиционный переключатель `SUP / OFF / DEM` (три варианта модели),
три гнезда-образца для фильтра (плоские площадки 4×4 /16, предмет рисует код), табличка под
номер, маленький пульт.

Тележка `monorail_carrier` (свой манифест и файл анимаций): `body`; `hoist` (траверса на тросах,
потомок `body`, ход y от −16 до 0 на одну клетку глубины); `grip_l`, `grip_r` (ход x ±1).
Клипы: `hoist_down`, `hoist_up` (1,5 с на клетку), `grip_open`, `grip_close` (0,3 с),
`ambient_run`. Один сигнальный огонь: три варианта (белый, фиолетовый, красный мигающий).
Два тира тележки отличаются меткой на корпусе.

Капсулы (props, привязка к `hoist`), все в первой очереди: `capsule_crate` (ящик с окном,
4 ступени уровня), `capsule_foup` (кассета, как на доках литографа), `capsule_ingot` (ложемент
со слитком), `capsule_tank` (бак для жидкости: стекло, 4 ступени уровня; саму жидкость сделать
отдельным элементом с белой текстурой — цвет задаёт код).

Кассета FOUP как предмет `foup` (первая очередь): та же модель, что на доках литографа и под
тележкой; модель предмета — кассета в руке; 4 ступени заполнения (пусто, 1–5, 6–11, 12–16
пластин видны через окно). Если модель на доках литографа сейчас часть клетки, нужна она же
отдельным prop.

Стрелка с пером `monorail_switch` (3×1×2, часть `blade`) — позже, в первую сдачу не входит.

## Архив 13: доработки пяти машин

Окон со слотами у машин больше не будет: предметы кладут руками в машину, состояние видно на
корпусе. Для этого нужны небольшие дополнения к готовым моделям (геометрию машин не менять).

### 1. Видимые предметы в точках загрузки и выдачи (props, модели `dyn/`)

Каждый — со ступенями заполнения (пусто не рисуется; 1/3, 2/3, полный), якорь и клетка в README.

| машина | точка | prop |
|---|---|---|
| литограф | лоток олова `tin` (7,1,0) | слитки олова в лотке |
| дуговая печь | горн (проём зонта) | уровень шихты: три высоты поверхности |
| дуговая печь | лоток `tap` (0,0,2) | слитки в изложнице у тележки |
| ростовая печь | люк `charge` (0,2,2) | гранулы поликремния в приёмном лотке |
| резка | кассета `wafers` (4,0,0) | кассета с пластинами |
| линия | лоток `chips` (1,0,2) | лоток с микросхемами |
| линия | магазин `boards` (2,1,1) | стопка заготовок плат |
| линия | выход `out` (13,1,1) | готовая плата на столе |

### 2. Подписи у точек

Короткая трафаретная надпись у каждой точки, тем же шрифтом, что `RETICLE` и `SOURCE`:
`WAFER IN`, `WAFER OUT`, `RETICLE`, `SN`, `CHARGE`, `TAP`, `INGOT`, `WAFERS`, `CHIPS`, `BOARDS`,
`OUT`, `POWER`. Где надпись уже есть — оставить.

### 3. Зоны взаимодействия

В README каждой машины — прямоугольник каждой точки (клетки и координаты в 1/16 блока): по нему
игра обводит точку рамкой при наведении.

### 4. Сигнальная лампа и лампа ввода

- `alarm_beacon`: красная лампа на пульте или над ним, 1 клетка, оформляется как люк: closed —
  погашена, open — мигает (анимированная текстура, 1 Гц).
- `power_lamp`: маленькая лампа у порта `power`: closed — погашена, open — белая.

### 5. Табло на пульте

На стекле пульта оставить чистый чёрный прямоугольник под две строки по 16 знаков (знак 8×16
экранных точек; на модели примерно 12×4 /16) и записать его координаты в манифест
(`readouts`: клетка, грань, прямоугольник). Текст рисует код; декоративные строки с этого места убрать.

### 6. Позже

Четвёртое состояние световых линий `fault` (красные, мигают) для всех пяти машин — решено
отложить: сначала лампа и табло. В эту сдачу не входит.

## Интерфейсы

Окон со слотами не будет совсем (решено): текстуры окон не нужны. Пульт открывает текстовую
консоль 80×25 и консольные программы шрифтом, который уже есть в моде. От художника для интерфейса — только то, что в архиве 13 (лампы, табло, подписи)
и иконки предметов 32×32 из архивов 11 и 12.

## Архив 14 (по желанию): декор завода

Демо-завод ([DEMO_FACTORY.md](DEMO_FACTORY.md), раздел «Отделка») собирается из ванильных блоков,
но несколько своих блоков заметно поднимут уровень. Все простые, без подвижных частей и клипов.

| блок | габариты | что |
|---|---|---|
| `wall_panel` | полный блок | фасадная панель Mk2: белая, шов по периметру, лёгкий шум. Варианты: гладкая, с жалюзи, с трафаретным номером (0–9) |
| `plinth` | полный блок | цоколь: чёрный анодированный, сверху фаска 1/16 |
| `raised_floor` | плита 16×16, высота 2/16 на четырёх стойках (итого 8/16) или полный блок | фальшпол: белая плитка с перфорацией; вариант без перфорации |
