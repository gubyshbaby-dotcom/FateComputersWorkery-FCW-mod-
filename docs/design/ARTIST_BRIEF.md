# ТЗ художнику: энергоблоки, автоматика, доработки машин

Minecraft Java 1.21.1, NeoForge. Пространство имён `pcmod`, как в прошлых наборах. Три архива:
`11_energy_blocks`, `12_automation`, `13_machine_updates`. Можно сдавать по одному.

Подробности и числа: [ENERGY_BLOCKS.md](ENERGY_BLOCKS.md), [AUTOMATION.md](AUTOMATION.md),
[MACHINE_UI.md](MACHINE_UI.md). Схемы пропорций (не модели, только размеры и расположение
индикаторов): [mockups/concept_energy.png](mockups/concept_energy.png),
[mockups/concept_automation.png](mockups/concept_automation.png).

## Общие правила

- Стиль Mk2, как у литографа и печи v4: белые корпуса с панелями по блоку, вставки из чёрного
  стекла, чёрные анодированные рамы, по низу юбка цоколя, 2 текселя на 1/16 блока, лёгкий шум на
  белом. Медь только на шинах, клеммах и наконечниках.
- Сдержанно. Светятся только: световые линии состояния (тёмные — off, белые — idle,
  фиолетовые — run), сигнальные лампы, строки на маленьких экранах, огонь. Никакого декоративного
  свечения, голограмм, RGB.
- Перед модели — север, `facing=north` без поворота. Повороты элементов только 22,5° и 45°.
  У граней на границе блока `cullface`. Светящиеся грани — `neoforge_data` (15/15).
- Состояния off / idle / run — отдельными моделями или текстурами, как раньше. Анимированные
  текстуры: кадры стопкой + `.mcmeta`.
- Мультиблоки и всё с подвижными частями: манифест + файл анимаций формата `format: 1`
  (части, клипы, props, events, fx, emitters), блоки `<имя>_part` и `<имя>_hatch`, модели `dyn/`,
  `alt_blockstates` с «голыми» клетками, тот же Java-проигрыватель.
- У каждого блока модель предмета; у мультиблоков — иконка комплекта 32×32.
- В README: части, свойства и их значения, порты (клетка, грань, координаты в 1/16), люки,
  подвижные части (якорь, ось, ход), клипы, эмиттеры частиц, что проверено, чего нет.
- Превью-листы как раньше: общий вид, состояния, соединения, точки подключения с номерами.

## Архив 11: энергоблоки

| № | блок | габариты | коротко |
|---|---|---|---|
| 1 | `solar_panel_poly`, `_mono`, `_hjt` | 1×1, высота 4/16 (плоская) или наклон 22,5° | рама, стекло с ячейками, ножки, рейка, снизу коробка с медным выводом и одним светодиодом |
| 2 | `solar_tracker` | мультиблок 3×5×3 | тумба с экраном, чёрная мачта, стол 3×3 панели на двух осях |
| 3 | `fuel_generator` | 1×1×1 + труба 6/16 | тёмная сталь, не Mk2: топка с решёткой, манометр, медная клемма сзади |
| 4 | `turbine_generator` | мультиблок 3×2×2 | Mk2: окно на турбину, вентилятор, выхлоп |
| 5 | `transformer` | 1×2×1 | бак с рёбрами, окно, три изолятора ВН сверху |
| 6 | `substation` | мультиблок 4×3×3 | портал с изоляторами и разъединителями, бак с радиаторами, шкаф с экраном, открытые медные шины |
| 7 | `hv_pylon`, `hv_insulator` | 1×3×1, 1×1×1 | чёрная стойка с траверсой и двумя изоляторами; одиночный изолятор на кронштейне |
| 8 | `ups_home` | 1×1×1, корпус 8×14×12 /16 | бытовой, тёмный, без RGB: кнопка, экранчик, шкала из 4 сегментов |
| 9 | `battery_cabinet` | 1×2×1, стыкуется в ряд | Mk2: стеклянная дверь, четыре полки с модулями |
| 10 | `cable_copper`, `cable_power`, `busbar` | 1×1×1, диаметр 4 / 6 / 8 из 16 | чёрная оболочка, метки тира: белое кольцо / фиолетовое / медные кольца |
| 11 | `cable_duct_copper`, `_power`, `_busbar` | полный блок | плита пола с рифлёной крышкой и прорезями, в прорезях виден кабель |
| 12 | `grid_tap_ae2` (по желанию) | 1×1×1 | куб Mk2 с окном в одну строку и медной клеммой |

Предметы-иконки 32×32: `battery_module_lead`, `_liion`, `_solid`, `hv_wire_coil`,
`solar_cell_poly`, `_mono`, `_hjt`, комплекты трёх мультиблоков.

### Состояния и свойства

| блок | свойства |
|---|---|
| панели | `facing`, `tilt` = flat / tilted, `west`, `east` (сосед: без заглушки рамы, одна ножка на стыке), `lit` (светодиод на коробке). Сама панель не светится и не меняется |
| три тира панелей | T1: синие ячейки с «искрой» кристаллов, видны шины. T2: почти чёрные ячейки со срезанными уголками. T3: сплошная чёрная, чёрная рама |
| `fuel_generator` | `facing`, `state`: off; idle — белый дежурный светодиод; run — пламя за решёткой (анимация), светодиоды нагрузки. Накладки уровня топлива в топке: 3 ступени |
| `transformer` | `facing`, `half`, `state` |
| `ups_home` | `facing`, `mode` = off / line / battery, `charge` = 0…4. Шкала зелёная от сети, янтарная от батареи; последний сегмент красный мигающий при 0 |
| `battery_cabinet` | `facing`, `half`, `state`, `west`, `east`, `open`. Накладки: модуль на полке (4 полки × 3 вида), уровень заряда на полке (5 ступеней × зелёный и янтарный) |
| кабели | multipart: `core` (муфта на 2/16 толще, только на поворотах, отводах и концах), `arm_<6 сторон>`, `plug_<6 сторон>` (воротник и медное кольцо у устройства), `clip_<6 сторон>` (скоба к стене) |
| опора ВН | `facing`, `part` = 0…2; в README — точки крепления проводов. Провод рисует код: нужна текстура 4×16 |

### Подвижные части и клипы

| блок | части | клипы |
|---|---|---|
| `solar_tracker` | `azimuth` (вокруг y, без предела), `tilt` (потомок, вокруг x, 0…60°), стол одной моделью | `wake` 3 с, `track` 60 с (растягивается на день), `stow` 3 с, `ambient_run` 2 с цикл |
| `turbine_generator` | `rotor` (вокруг x), `fan` (вокруг z); люки `main_breaker`, `service_door` | `spin_up` 4 с, `run` 1 с цикл, `spin_down` 6 с, `ambient_idle` 4 с цикл |
| `substation` | `disconnector_1..3` (вокруг z, 0…60°), `tank_fan_1..2`; люки `main_breaker`, `alarm_beacon` (лампа: closed — погашена, open — мигает красным) | `switch_on` 2 с, `switch_off` 2 с, `ambient_idle` 4 с цикл, `ambient_run` 2 с цикл |
| `battery_cabinet` | `door` (вокруг y, 0…100°) или два статических варианта | `door_open`, `door_close` по 0,6 с |

Частицы: `generator_smoke` (труба генератора), `turbine_heat`, `turbine_smoke`, `arc_flash`,
`arc_spark` (разъединители подстанции). Спрайты и описания эмиттеров — как у печи.

Порты (подробно в ENERGY_BLOCKS.md): у мультиблоков `power`, `terminal`, `main_breaker`; у
турбогенератора ещё `fuel`, `exhaust`; у подстанции `hv_in`, `feeder_1..4`, `data`.

Превью: общий вид; состояния; соединения (поле панелей 4×3 плоское и наклонное, банк из трёх
шкафов, кабели: прямой, угол, тройник, крест, ввод в машину, канал в полу); точки подключения.

## Архив 12: автоматика

### Монорельс (подвесной)

Балка занимает верхние 6/16 клетки, тележка — нижние 10/16, капсула с грузом висит в клетке ниже.
Балка белая, подвесы чёрные, по низу балки световая линия состояния.

| № | блок | клетки | подвижные части | клипы |
|---|---|---|---|---|
| 1 | `monorail_track` | 1×1×1 | — | свойства `axis`, `hanger` = none / ceiling / post, `state` |
| 2 | `monorail_curve` | 2×1×2 | — | четыре ориентации |
| 3 | `monorail_switch` | 3×1×2 | `blade` (вокруг y, 0…20°), огонь пути | `to_branch`, `to_main` по 0,6 с |
| 4 | `monorail_lift` | 1×N×1 | `cage` (люлька с отрезком балки, ход по y) | `lift_up`, `lift_down`, 1 с на клетку |
| 5 | `monorail_station` | 1×1×1 | `clamp_l`, `clamp_r` (ход x ±2) | `clamp_close`, `clamp_open` по 0,4 с |
| 6 | `monorail_depot` | 1×2×2 | `shutter` (ход по y) | `shutter_open`, `shutter_close` по 1 с |
| 7 | `monorail_post` | 1×N×1 | — | стойка-портал для улицы |
| 8 | `monorail_gate` | 1×1×1 | `door_l`, `door_r` (ход вбок) | `gate_open`, `gate_close` по 0,5 с |

На корпусе станции: трёхпозиционный переключатель `SUP / OFF / DEM` (три варианта модели),
три гнезда-образца для фильтра (плоские площадки 4×4 /16, предмет рисует код), табличка под
номер, маленький пульт.

Тележка `monorail_carrier` (свой манифест и файл анимаций): `body`; `hoist` (траверса на тросах,
потомок `body`, ход y от −16 до 0 на одну клетку глубины); `grip_l`, `grip_r` (ход x ±1).
Клипы: `hoist_down`, `hoist_up` (1,5 с на клетку), `grip_open`, `grip_close` (0,3 с),
`ambient_run`. Один сигнальный огонь: три варианта (белый, фиолетовый, красный мигающий).
Два тира тележки отличаются меткой на корпусе.

Капсулы (props, привязка к `hoist`): `capsule_crate` (ящик с окном, 4 ступени уровня),
`capsule_foup` (кассета, как на доках литографа), `capsule_ingot` (ложемент со слитком),
`capsule_tank` (бак, 4 ступени уровня).

### Манипуляторы

| блок | база | вылет | особенности |
|---|---|---|---|
| `arm_s` | 1×1 | 2 блока | пол и потолок |
| `arm_m` | 1×1 | 4 блока | пол, потолок, каретка напольного рельса |
| `arm_l` | 2×2 | 6 блоков | берёт слиток и кассету; достаёт до y = +5 |
| `arm_rail` | 1×1, высота 4/16 | — | две направляющие, зубчатая рейка, кабельная цепь |
| `arm_carriage` | 1×1 | — | каретка под `arm_m` |

Части (у всех трёх размеров одинаковые имена): `turret` (вокруг y), `upper_arm` (потомок, вокруг x,
−20…110°), `forearm` (вокруг x, 0…150°), `wrist` (вокруг x), `grip_l`, `grip_r` (ход x ±1,5).
В манифесте дополнительно длины звеньев и точка захвата: движение к целям считает код.
Prop `held` привязан к `wrist`.

Клипы: `home` 1 с, `grip_close`, `grip_open` по 0,3 с, `ambient_idle` 4 с цикл, `fault` 1 с.
На базе: кнопка `TEACH`, лампа (белая мигающая / красная мигающая — два варианта), гнездо-образец
фильтра, световая линия на плече.

Превью: линия с поворотом, стрелкой, станцией над машиной и депо; тележка с каждой капсулой;
манипуляторы S, M, L (сложен, вытянут, с предметом), M на каретке и на потолке; состояния.

## Архив 13: доработки пяти машин

Окон со слотами у машин больше не будет: предметы кладут руками в машину, состояние видно на
корпусе. Для этого нужны небольшие дополнения к готовым моделям (геометрию машин не менять).

### 1. Видимые предметы в точках загрузки и выдачи (props, модели `dyn/`)

Каждый — со ступенями заполнения (пусто не рисуется; 1/3, 2/3, полный), якорь и клетка в README.

| машина | точка | prop |
|---|---|---|
| литограф | лоток олова `tin` (7,1,0) | слитки олова в лотке |
| дуговая печь | горн (проём зонта) | уровень шихты: три высоты поверхности |
| дуговая печь | лоток `tap` (0,0,2) | слитки в изложнице у тележки |
| ростовая печь | люк `charge` (0,2,2) | гранулы поликремния в приёмном лотке |
| резка | кассета `wafers` (4,0,0) | кассета с пластинами |
| линия | лоток `chips` (1,0,2) | лоток с микросхемами |
| линия | магазин `boards` (2,1,1) | стопка заготовок плат |
| линия | выход `out` (13,1,1) | готовая плата на столе |

### 2. Подписи у точек

Короткая трафаретная надпись у каждой точки, тем же шрифтом, что `RETICLE` и `SOURCE`:
`WAFER IN`, `WAFER OUT`, `RETICLE`, `SN`, `CHARGE`, `TAP`, `INGOT`, `WAFERS`, `CHIPS`, `BOARDS`,
`OUT`, `POWER`. Где надпись уже есть — оставить.

### 3. Зоны взаимодействия

В README каждой машины — прямоугольник каждой точки (клетки и координаты в 1/16 блока): по нему
игра обводит точку рамкой при наведении.

### 4. Сигнальная лампа и лампа ввода

- `alarm_beacon`: красная лампа на пульте или над ним, 1 клетка, оформляется как люк: closed —
  погашена, open — мигает (анимированная текстура, 1 Гц).
- `power_lamp`: маленькая лампа у порта `power`: closed — погашена, open — белая.

### 5. Табло на пульте

На стекле пульта оставить чистый чёрный прямоугольник под две строки по 16 знаков (знак 8×16
экранных точек; на модели примерно 12×4 /16) и записать его координаты в манифест
(`readouts`: клетка, грань, прямоугольник). Текст рисует код; декоративные строки с этого места убрать.

### 6. По желанию, отдельным шагом

Четвёртое состояние световых линий `fault` (красные, мигают) для всех пяти машин. Делать только
после подтверждения: это новый набор текстур на каждую машину.

## Интерфейсы

Текстуры окон не нужны: окон нет. Пульт открывает текстовую консоль 80×25 шрифтом, который уже
есть в моде. От художника для интерфейса — только то, что в архиве 13 (лампы, табло, подписи)
и иконки предметов 32×32 из архивов 11 и 12.

## Порядок

1. Архив 13 (небольшой, нужен первым: без него нельзя убрать окна).
2. Архив 11: сначала кабели, генератор, панели, ИБП; затем трансформатор, подстанция, трекер,
   турбогенератор.
3. Архив 12: балка, тележка, станция, депо; затем манипуляторы; затем стрелка, подъёмник, шлюз.
