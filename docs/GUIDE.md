# Обучающие материалы: справочник и сцены Ponder

В моде два вида встроенной документации:

- **справочник**: книга на GuideME, страницы в Markdown с трёхмерными сценами машин и рецептами;
- **сцены Ponder**: анимированные сцены мультиблоков (постройка, порты, цепочка).

Обе библиотеки необязательны: без них мод работает как раньше.

## Библиотеки

| Библиотека | Версия | Как подключена | Почему |
|---|---|---|---|
| GuideME (`org.appliedenergistics:guideme`, Maven Central) | 21.1.22 | внутри jar мода (Jar-in-Jar), в `neoforge.mods.toml` помечена `optional` | справочник должен быть в каждой установке без отдельной загрузки; диапазон версий `[21.1.22,21.2)`, при нескольких копиях в сборке (GuideME требует, например, AE2) загрузчик выбирает одну по правилам Jar-in-Jar |
| Ponder (`net.createmod.ponder:Ponder-NeoForge-1.21.1`, maven.createmod.net) | 1.0.69 | только `compileOnly`; в игре берётся, если установлена (идёт с Create 6) | Ponder тянет за собой Flywheel и нужна только клиенту; сцены дополняют справочник, а не заменяют его |
| Flywheel | 1.0.5 | только для запуска из Gradle (`localRuntime`) | её требует Ponder на клиенте |

Используемое API Ponder не менялось с 1.0.24, первой сборки под NeoForge 1.21.1.

Всё это собрано в одном блоке `guide and Ponder` в `mod/build.gradle`; версии в `mod/gradle.properties`.

## Где что лежит

| Путь | Что |
|---|---|
| `mod/src/main/java/.../compat/DocsCompat.java` | вторая клиентская точка входа мода: проверяет `ModList` и подключает справочник и сцены. Единственный класс, который знает о библиотеках |
| `.../compat/guideme/` | справочник `fcw:guide`, рамки рецептов машин, теги портов |
| `.../compat/ponder/` | плагин Ponder и раскадровки сцен |
| `.../docs/DocStructures.java` | раскладка структур для сцен и их выгрузка из мира |
| `assets/fcw/fcwguide/` | страницы: английские в корне, русские в `_ru_ru/` |
| `assets/fcw/fcwguide/assets/structures/` | структуры для сцен справочника (машины без пола) |
| `assets/fcw/ponder/` | структуры для Ponder (машины на полу) |
| `assets/fcw_docs/lang/` | тексты сцен Ponder, названия портов, подписи рецептов, название книги |
| `assets/guideme/lang/ru_ru.json` | русские подписи интерфейса GuideME (в самой библиотеке только английские) |
| `data/fcw_docs/recipe/guide.json` | рецепт книги: книга + заготовка платы; работает только при наличии GuideME |
| `mod/tools/guide/check.py` | проверка: страницы и ключи совпадают в двух языках, ссылки и структуры существуют |

Тексты и рецепт лежат в отдельном пространстве имён `fcw_docs`, чтобы не пересекаться с `assets/fcw/lang` и с `data/fcw/recipe`, который целиком пересоздаёт `mod/tools/production/gen.py`.

## Страницы справочника

Формат GuideME: Markdown с тегами. Кроме штатных тегов есть три своих:

| Тег | Что делает |
|---|---|
| `<MachineRecipes type="fcw:arc_furnace" />` | все рецепты одного типа, включая рецепты датапаков |
| `<MachinePorts machine="arc_furnace" />` | внутри `<GameScene>`: цветные рамки на портах машины, название в подсказке |
| `<MachinePortTable machine="arc_furnace" />` | таблица портов: порт, что идёт, сторона |

Штатные `<Recipe id=... />` и `<RecipeFor id=... />` тоже понимают рецепты машин.

Порты, их клетки и роли читаются из манифеста машины и `MachineSpec`, рецепты из менеджера рецептов. Поэтому в страницах нет ни координат, ни чисел из рецептов: при правке баланса или модели страницы менять не нужно.

Вручную записаны: размеры и число клеток машин, число слотов, состав слоёв литографа (страница `production/euv-building.md`), таблицы на страницах «Комплектующие», «Энергия», «Настройки», «Команды».

### Правка страниц

При запуске `./gradlew runClient` клиент читает страницы прямо из исходников и перечитывает их при сохранении файла: достаточно держать книгу открытой.

Открыть нужную страницу: `/guideme open @s fcw:guide fcw:production/arc-furnace.md`.

Особенности разметки:

- знаки `<`, `>`, `{`, `}` в тексте разбираются как теги: пишите такие вещи в обратных кавычках;
- в блоках кода не делайте отступов: строки с отступом GuideME переносит неправильно;
- каждая страница существует в двух языках с одинаковым набором тегов; это проверяет `check.py`.

## Обновление после изменения машин

Структуры сцен не рисуются вручную: сервер ставит настоящие машины в мир и сохраняет их так же, как блок структуры.

```
cd mod
./gradlew runServer -Pfcw.docsExport
```

Сервер запишет файлы в `assets/fcw/ponder` и `assets/fcw/fcwguide/assets/structures` и остановится. Нужен `run/server/eula.txt` с `eula=true`.

Тексты сцен Ponder пишутся по-английски прямо в раскадровках (`MachineScenes.java`). Ponder берёт текст только из языковых файлов, поэтому английский файл собирается из кода:

```
./gradlew runClient -Pfcw.docsExport
```

После входа в любой мир ключи `fcw.ponder.*` в `assets/fcw_docs/lang/en_us.json` перезаписываются. Русские тексты с теми же ключами правятся вручную в `ru_ru.json`. Номера `text_N` идут по порядку шагов сцены: если добавить шаг в середину, номера следующих сдвинутся.

Затем:

```
python3 mod/tools/guide/check.py
```

## Что править после переделки управления машинами

Устройство машин, порты и рецепты берутся из данных и обновятся сами. Порядок управления описан в немногих местах:

| Место | Что там |
|---|---|
| страница `production/operation.md` (оба языка) | установка, запуск, состояния, порты: вся страница |
| `MachineScenes.java`, `SHARED`: `port_panel`, `port_breaker` и те же ключи в `ru_ru.json` | две фразы в сценах портов |
| `MachineScenes.java`, сцена `kit`: `kit_front` | фраза про пульт, обращённый к игроку |
| страница `production/euv-scanner.md`, абзац под таблицей портов | как грузятся пластины и фотошаблон |
| страница `production/euv-building.md`, шаг 5 | где рубильник |
| страницы машин, строка «Слоты» | число входных и выходных слотов |
| `guide.fcw.port.kind.gui`, `guide.fcw.port.kind.item_catalyst` | подписи «управление», «слот шаблона» в таблице портов |
| страница `energy/index.md` | буфер, приём, поведение при нехватке энергии |
| страница `reference/commands.md` | добавить `fcw machine ...` в раздел «В гостевой системе» |

## Проверка без библиотек

```
./gradlew runServer -Pfcw.noDocLibs
./gradlew runClient -Pfcw.noDocLibs
```

Запускает мод без GuideME, Ponder и Flywheel, как у игрока, у которого их нет.
