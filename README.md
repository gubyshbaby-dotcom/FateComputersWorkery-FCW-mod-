# Fate Computers Workery (FCW)

Мод для Minecraft Java 1.21.1 (NeoForge): в мире стоят настоящие компьютеры.
Внутри каждого крутится своя виртуальная машина с Linux: Fedora, Ubuntu или
Arch с готовым рабочим столом (labwc + панель LXQt), терминал — Alacritty.
Экран компьютера виден на мониторе прямо в мире, а с клавиатурой и мышью
можно сесть за компьютер и работать.

## Как устроено

```
 клиент игрока                сервер Minecraft              демон ВМ (Rust)                гостевая ВМ (QEMU)
 ┌──────────────┐  TCP MC    ┌────────────────┐  Unix-сокет ┌──────────────────┐  virtio     ┌───────────────────┐
 │ мод (Java)   │◄──────────►│ мод (Java)     │◄───────────►│ API управления   │◄───────────►│ labwc + lxqt-panel│
 │ блоки, GUI   │  токен     │ блоки, мост    │  protobuf   │ планировщик      │  gpu/input  │ Alacritty         │
 └──────┬───────┘            └────────────────┘             │ стример экранов  │  console    │ tty на hvc0       │
        │ JNI                                               │ текстовые экраны │  serial     │ агент мира (fcw)  │
 ┌──────┴───────┐        QUIC по UDP, напрямую              │ диспетчер ввода  │  blk        │                   │
 │ libfcw_client│◄─────────────────────────────────────────►│ QUIC-сервер      │             └───────────────────┘
 │ кадры, текст │  кадры (дельты тайлов), текст, ввод, звук │ хранилище: база  │
 └──────────────┘                                           │ + свой слой qcow2│
                                                            └──────────────────┘
```

- Пиксели и ввод идут мимо игрового тика: сервер Minecraft только выдаёт
  одноразовые токены, а клиент игрока сам подключается к демону по QUIC.
  Сертификат демона закреплён: отпечаток приходит от сервера.
- Демон запускает QEMU с virtio-устройствами. Ускорение: KVM (Linux), WHPX
  (Windows), HVF (macOS на Intel), иначе TCG (медленно, но работает везде).
- Диск каждой машины — тонкий слой qcow2 поверх общей базы образа: десять
  компьютеров с Fedora занимают место одного образа плюс изменения.
- Без видеокарты компьютер работает в текстовом режиме: монитор показывает
  консоль `hvc0`. С видеокартой появляется рабочий стол.

Полные контракты между частями: [`docs/CONTRACT.md`](docs/CONTRACT.md),
протоколы: [`native/proto/`](native/proto).

## Что в репозитории

| каталог | что |
|---|---|
| `mod/` | мод NeoForge 1.21.1 (Java 21, Gradle, ModDevGradle), modid `fcw` |
| `native/` | Cargo workspace: `fcw-daemon` (демон ВМ), `fcw-client` (JNI-библиотека клиента), `fcw-probe` (консольный клиент для проверок), `fcw-agent` (агент внутри гостя), `fcw-proto` |
| `images/` | сборка гостевых образов Fedora 45, Ubuntu 26.04 LTS, Arch Linux |
| `docs/` | контракты и заметки |

## Гостевые образы

Все три собираются одинаково: официальная база дистрибутива → chroot →
родной пакетный менеджер (dnf / apt / pacman) → общая настройка → ext4 →
qcow2 + ядро + initrd + `manifest.json`.

Что внутри:

- рабочий стол **labwc** (Wayland, рисует через pixman: видеокарта гостя без 3D)
  + **lxqt-panel** (меню, быстрый запуск, панель задач, звук, часы), обои и
  цвет заголовков в цвет дистрибутива;
- **Alacritty** — единственный эмулятор терминала (Super+Enter или Ctrl+Alt+T,
  кнопка на панели); остальные терминалы из образа удалены;
- файловый менеджер pcmanfm-qt, PipeWire, systemd-networkd (DHCP);
- автологин пользователя `user` (пароль `fcw`, есть sudo) на рабочем столе
  и в текстовой консоли `hvc0` (80x25, xterm-256color);
- раскладки us + ru (Alt+Shift), язык и часовой пояс передаются из игры;
- агент `fcw` (редстоун и связь с миром) запускается сам, если ВМ дали канал.

Сборка (нужен root, Linux, `qemu-img`, `zstd`, `mkfs.ext4`):

```bash
sudo ./images/build-image.sh fedora
```

```bash
sudo FCW_AGENT_BIN=native/target/x86_64-unknown-linux-musl/release/fcw ./images/build-image.sh arch out work
```

Готовый образ: `out/<id>/` и архив `out/fcw-image-<id>.tar.zst`. Проверить
без игры и демона:

```bash
python3 images/test-boot.py out/fedora /tmp/fcw-test --gpu --keys meta_l-ret
```

Скриншоты появятся в `/tmp/fcw-test/`. CI собирает образы по тегу `images-*`
или вручную (`.github/workflows/images.yml`) и выкладывает их в релиз `images`.

## Требования для игры

- Minecraft Java 1.21.1 + NeoForge 21.1.x.
- На машине, где работает сервер (в одиночной игре — у самого игрока):
  QEMU (`qemu-system-x86_64` и `qemu-img`). Linux: пакет `qemu-system-x86`;
  Windows: установщик QEMU, плюс компонент «Платформа низкоуровневой
  оболочки Windows» для WHPX; macOS: `brew install qemu`.
- Гостевые образы в `<папка игры>/fcw/images/<id>/`: скачиваются командой
  `/fcw images fetch <id>` или вручную из релиза `images`.
- Для игры по сети открыть UDP-порт демона (по умолчанию 25600).
